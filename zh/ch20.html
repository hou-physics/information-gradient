第 20 章　坏消息、卖空约束与动量

Hong、Lim 与 Stein（2000）把美国股票按规模分组，在每个规模组里测量动量（momentum），即过去赢家的收益减去过去输家的收益，数据取自 1980 年至 1996 年（工作论文版的数字）。在最小的那批股票里，平均市值为 700 万美元，动量为负；动量在规模第三个十分位达到最高，那里的平均市值约为 4500 万美元，为每月 1.43%（t 统计量 6.66），几乎是整个样本的值的三倍，到最大的股票里降到基本为零（工作论文版的数字）。

他们的第二个检验用残差分析师覆盖（residual analyst coverage），即关注一只股票的分析师人数，相对于这只股票的规模来衡量，并剔除低于纽约证交所/美国证交所规模第 20 百分位分界点的所有股票，因为其中绝大多数从来没有分析师（工作论文版的数字）。残差覆盖低的股票，动量为每月 1.13%，覆盖高的为 0.72%，差为 0.42%，t 统计量为 3.50；覆盖的影响完全来自输家，低覆盖的输家每月比高覆盖的输家差 0.70%，t 统计量为 5.16（工作论文版的数字）。赢家之间的差别稍稍偏向“错误”的方向，在他们的一张表里统计显著，作者写道，这一点比他们的其他结果脆弱得多（工作论文版）。

作者把这些发现读作与下面的假说一致：公司特有的信息，尤其是负面信息，只会逐步地在投资大众中扩散（工作论文版）。20.1 节问坏消息（bad news）在卖空约束（short-sale constraint），即对卖出借来的股票的限制之下，在哪里失去速度；20.2 节问在 Hong 与 Stein（1999）的模型里动量从哪里来，Hong、Lim 与 Stein 检验了这个模型在不同股票之间的预测，检验的是它的延续一侧（20.2.4 节）。1

20.1 坏消息的速度与卖空约束

根模型（root model）的价格规则需要卖空（short selling），卖空是它默认的无摩擦交易（frictionless trading）的一部分（1.5 节和 5.3 节；表 5.1）。本节去掉这一部分，即卖空交易（short sale）被禁止、成本高，或者所得款项的用途受到限制。

20.1.1 坏消息变慢的三层

坏消息可以在三个层面上变慢（本书的判断；表 20.1）。在知晓层（awareness layer），消息还没有传到足够多的人，例如管理者可能压下坏消息。在价格层（price layer），知情的人不能把价格压得足够低，原因是卖空受到限制、人与人之间的分歧又无法从价格里学到，或者是一项约束改变了私人信息（private information）进入按理性预期（rational expectations）定出的价格的速度。在行动层（action layer），知情的人仍然可能等待，因为持有空头比持有多头更贵。从价格到管理者决策的反馈（feedback）加上了一种不对称的套利限制（limits to arbitrage；20.1.7 节），而同样的坏消息变慢可以出自任何一层，所以检验必须先说明它针对的是哪一层（本书的判断）。2

20.1.2 压下坏消息的发送者

Hong、Lim 与 Stein 自己的读法（15.2.2 节）是：有好消息（good news）的管理者大概有十足的动机把它快速发布出去，有坏消息的管理者则可能不那么坦率，所以外部分析师更重要；卖空约束也许是解释的一部分，不过单靠它似乎解释不了为什么分析师越少，这一效应越强（工作论文版）。证据是开头那个交互效应，即低覆盖与过去的输家；管理者的行为是作者的解释，他们没有直接检验（本书的判断；15.2.2 节）。

同一个交互效应分不开知晓层和行动层（本书的判断）。Abreu 与 Brunnermeier（2002）写道，他们对坏消息传得慢的说明，与 Hong、Lim 与 Stein 的发现相符，即分析师覆盖（analyst coverage）低的股票对坏消息的反应似乎比对好消息的反应更迟缓。如果分析师少意味着套利者得知错价的时间更分散，20.1.6 节的行动层机制也给出同样的交互效应，要把两者分开，还需要另一项检验，例如比较同一类错价在借股便宜和借股昂贵的股票里持续多久（本书的判断）。

Hong、Lim 与 Stein 的预测还假设，聪明钱的套利（arbitrage）没有把各只股票之间动量的差别完全消除（工作论文版），本书把这读作套利者的风险承担能力（risk-bearing capacity）问题，在第 23 章处理（本书的判断）。3

20.1.3 学不到的分歧

卖空受限时，价格是否高于平均估值，在 Miller、Harrison 与 Kreps、Scheinkman 与 Xiong 的设定里，取决于人与人之间的分歧能否从价格里学到（本书的判断）。有两种情形学不到。第一种情形里，没有人根据交易所揭示的东西作出理性推断。Diamond 与 Verrecchia（1987）写道，现有的研究，包括 Miller 的研究，得出的结论是：约束悲观者而不约束乐观者，会使股价向上偏；这类工作假设“规则”不变；这些论文里没有一篇的投资者具有理性预期，这里指的是根据价格与交易推断别人知道什么（16.1 节）。他们指出，在 Jarrow（1980）的模型里，这个偏差可以为正、为负或为零（据 Diamond 与 Verrecchia 的转述），所以即使没有理性预期，向上的偏差也不是普遍的（本书的判断）。根模型里的交易者不从价格学习，也属于这一情形（本书的判断）。第二种情形里，人们的先验不同，或者对同一信息的读法不同，如 Harrison 与 Kreps（1978）以及 Scheinkman 与 Xiong（2003）。这两个模型去掉了带共同先验（common prior）的贝叶斯更新（Bayesian updating）这一默认，在它们里面，这一点加上卖空禁令就足够了；它并非必要，因为按贝叶斯法则（Bayes’ rule）用自己的信息更新、又不从价格学习的交易者，同样保留着价格教不会的分歧（本书的判断）。

Miller（1977）的静态论证（19.3.6 节；5.3 节给出了他的设定）如下。如果每个投资者只能买一股，共有 NN 股，这些股票最终由对收益估价最高的 NN 个投资者持有。只要潜在买者中的少数人就能吸收全部供给（这是通常的情形），市场价格就高于潜在投资者的平均估价，分歧越大，市场出清价格越高；只有在没有分歧时，平均估价才决定价格。去掉他的风险中性（risk neutrality）假设，论证不变，因为他的投资者用的是标准的组合理论，其中可以容纳风险厌恶（risk aversion），而且足够多的卖空可以把价格压到全体投资者的平均估价。反方向还有一股力量，即如果有足够多的投资者在评估投资时用不确定性溢价（uncertainty premium），风险投资的价格会趋于下降；他得出结论，既然分歧很可能随风险增大，风险证券的预期收益很可能更低。这个论证讲的是市场出清价格的水平，对调整的速度没有说什么，它回答了 10.4 节的问题，即卖空受限时，个人误差的散布更宽，本身就能抬高价格（本书的判断）。

在 Harrison 与 Kreps 的市场里（13.3 节），投资者共享全部信息，只是各类投资者对它的读法可能不同，最低一致价格（lowest consistent price）通常高于每个投资者对股息的预期现值，这是一种投机溢价（speculative premium）；它的精确结论依赖于风险中性、无限财富和禁止卖空，而且在只剩一期时、在投资者全都相同时，或者在针对或有债权的市场完全而完美时，都不会出现。Scheinkman 与 Xiong（2003）建立了一个连续时间的版本，其中有一种供给有限的风险资产和许多风险中性的主体；信息对所有人可得，两个群体各自高估了一个不同信号的信息量，并且因行为上的局限而彼此同意各持己见。在有卖空约束时，买者获得一份期权，可以在别人更乐观时把资产卖给他们，这就是转售期权，所以主体愿意付出高于他们自己对未来股息的估价的价格；泡沫（bubble）来自意见的分歧，平均而言主体既非乐观者也非悲观者。作者为技术上的原因直接排除了卖空，并写道，只要持有者可以预期在别人对资产估值更高时获利，他们的定性（qualitative）结果在卖空有成本时仍会成立。在他们的均衡（equilibrium）里，泡沫伴随着很大的成交量（trading volume）和很高的价格波动。

本书还把转售期权读作单一外生事实（single exogenous fact）这一默认的一个分支，因为价格的一部分取决于别人将来对这一事实的看法；Scheinkman 与 Xiong 的股息不依赖交易，符合这一默认的字面要求，所以这样归类只是一种读法（本书的判断；第 22 章）。

在没有理性预期的模型里，Diamond 与 Verrecchia 描述了一种直觉，即成本高的卖空使交易者群体里只剩下相对乐观的人，从而使价格对私人坏消息的调整变慢；Harrison 与 Kreps 的投资者拥有同样的信息，所以那里不出现私人的坏消息。18.7 节把高估（overvaluation）算作实测超额收益（measured excess return）中负的一部分（本书的推导；表 18.1），这种高估来自本节的两种情形，每一种都有受限的卖空（本书的判断）。4

20.1.4 理性预期与调整的速度

Diamond 与 Verrecchia（1987）问的是，交易者形成理性预期时，卖空约束起什么作用；这个模型把“不从价格学习”（no learning from prices）和无摩擦交易里的卖空部分一并去掉（本书的判断）。他们的模型沿用 Glosten 与 Milgrom（1985），其中做市商是风险中性的，没有库存成本或约束，每笔交易的预期利润为零，交易者是风险中性的，要么是知情交易者（informed trader），要么是未知情交易者（uninformed trader）。当卖空受到约束是共同知识、交易的差别来自信息而与偏好无关时，理性预期改变了“规则”，消除了价格的任何向上偏差。价格是在给定全部公共信息时资产价值的条件期望，所以在利率为零时，它在任何一天的无条件预期变动都为零，这个结果只依赖理性预期和风险中性。

方向取决于约束挡住的是谁（本书的判断）。按他们的命题 1，当所有能卖空的交易者都可以无成本地卖空时，价格对坏消息和对好消息调整所需的预期期数都随被禁止卖空的交易者所占比例上升，坏消息所需时间与好消息所需时间之比也随之上升。他们的成本函数与交易者的信息水平无关，所以被禁止的比例在知情与未知情交易者中相同，这时没有交易的一期既有一些信息量，又是坏消息（数学框 20.2）。按他们的命题 2，在所得款项限制（proceeds-restrictions）之下，即不让卖空者（short seller）立即使用所得款项，预期调整时间和它们的比值都随受其约束的交易者所占比例上升而下降，而且没有交易的一期不改变未来的买价与卖价。

作者论证，这些效应不太可能占主导，因为在一个更一般的、有很知情和有些知情两类交易者的模型里，只触及有些知情者的成本可以像禁令一样降低效率。他们的结论是，按知情与未知情交易者各占的人口比例禁止交易的约束，会降低无条件的信息效率，对私人坏消息尤其如此；而就理论而言，只限制未知情者交易的约束会提高信息效率，对私人坏消息尤其如此，他们论证前一种效应在实践中很可能占主导。

理性预期使价格无偏，所以这个模型不预测宣布坏消息时价格变动的绝对值平均而言更大。在禁令占主导的情形里（他们认为这种情形更可能，在另一种情形里预测相反），作者预测，引入期权交易应当减小公告日价格变动的左偏；论文本身没有检验这个预测（本书的判断）。5

20.1.5 理性预期下的期望泡沫

在理性预期下，Allen、Morris 与 Postlewaite（1993）证明，期望泡沫（expected bubble），即在某个日期和状态下价格高于每个主体的边际估值，要求卖空约束在未来的某种情形里严格起作用（据 Brunnermeier 的转述）；21.2.1 节给出了他们的定义和 Tirole 的条件。在他们的四个强泡沫（strong bubble）例子里，交易的收益分别来自异质的信念（belief）、依赖状态的效用、在效用相同且为凹的情形下的随机禀赋，或者在效用函数各不相同且为凹的情形下中期帕累托无效的初始配置（据 Brunnermeier 的转述）。第一个是 20.1.3 节里学不到的分歧的第二种情形；另外三个例子有理性预期和私人信息，这一分支不属于那种情形（本书的判断），而按本书对 Brunnermeier 所列清单的读法，它们有共同先验（本书的推论）；本书没有读过原文。6

20.1.6 更贵的空头

在行动层，Abreu 与 Brunnermeier（2002）的套利者以均匀的速率先后意识到新的基本面价值，所以在任何时点上，这个错价在他们之间都不是共同知识，并且为简单起见，所有人都是风险中性的（21.2.4 节）。在表 5.1 为本章列出的放宽（relaxation）之外，从未成为共同知识的错价去掉了一阶知识（first-order knowledge）这一默认，即交易者只需要知道事实本身（本书的判断；21.2 节）。作者用一个持有成本 cc 概括保持仓位的显性成本和隐性成本，它使套利者谨慎，并给他们推迟交易的动机，也可以看作对风险套利仓位所要求的风险溢价（risk premium）的一种简化。一个例子是召回风险，即借出股票的一方一旦召回，卖空者就得在不利的条件下买入平仓。

作者指出，这个模型可以扩展到不对称的持有成本，空头的持有成本通常高于多头的；他们写道，在他们的模型里，定价过高于是比定价过低持续得更久，所以实际上“坏消息传得慢”。他们补充了一个例外。即使是买入被低估资产的风险厌恶套利者，也可能想卖空相近的替代品来对冲，所以证券被低估时也可能出现卖空成本。他们的 5.1 节用文字讨论了这一扩展，没有为它建模（本书的判断）。由于 cc 把摩擦和风险溢价合在一起，仅凭延迟分辨不出是两者中的哪一个拖住了套利者（本书的判断）；第 23 章处理风险承担能力。

前面的两个例子适用于此处（本书的判断）：11.6 节的挤压（squeeze）与召回风险属于同一类摩擦，而在 EntreMed 的例子里（1.6.3 节），卖空成本高或卖空难，会是持有成本拖延纠正的一种途径。7

20.1.7 反馈与其他不对称的限制

16.8 节给出了管理者从股价里学习时，反馈造成的两种不对称，一种在 Goldstein 与 Guembel 的模型里，未知情的卖出可以获利，而未知情的买入亏损，另一种在 Edmans、Goldstein 与 Jiang 的模型里，一种抑制知情卖出、鼓励知情买入的套利限制（据 Bond、Edmans 与 Goldstein 的转述；工作论文版）。综述的作者们写道，信息反馈为几种原本似乎令人费解的现象给出了自然的解释，其中有操纵性卖空以及坏消息与好消息的不对称传播（工作论文版）。按本书的读法，反馈与卖空约束、压下坏消息的管理者并列，也使坏消息变慢，并提示一项检验：在管理者可以更灵活地根据价格改变决策的公司里，负面的私人信息进入价格应当更慢（本书的判断）。8

20.1.8 没有套利的预期下跌

在 Jouini 与 Kallal（1995a）的结果里，设有卖空约束，交易者只可以使用简单策略并共有同一种信息结构（information structure），价格在本书的读法里不受交易影响（本书的判断）。在这些前提下，没有免费午餐（free lunch），即大致没有不要风险也不要资本的收益，当且仅当在某个增长率介于借出利率与借入利率之间的计价单位（unit of account）之下，并在某个等价测度（equivalent measure），即含有相同可能事件的测度之下，不能卖空的证券的价格是上鞅（supermartingale），即平均而言不上升的过程，而只能持有空头的证券的价格是下鞅（submartingale）。因此，不能卖空的证券可以预期下跌而不提供套利，因为利用这个下跌需要卖空；这个下跌是在定价测度下以计价单位度量的预期，而在真实概率下，有风险的漂移（drift）不受摩擦所划出的区间的约束（本书的判断；5.4 节）。3.7 节完整地给出了这个结果。

均衡说得更多。Jouini 与 Kallal 写道，除非资产的净供给为零，没有免费午餐并没有穷尽均衡的全部含义，即供给为正的资产必须由某个主体持有，所以它的价格必须是鞅（martingale），即没有漂移的过程，对这个主体的跨期边际替代率所诱导的概率测度而言如此，而其他资产不必如此，因为由于卖空约束，它们可能由边际替代率不同的其他主体持有。

Harrison 与 Kreps 的例子显示了这两点。在他们的一致价格之下，所有投资者都认为投机（speculation）不比公平赌博更好；对于在某个状态下持有股票的那一类，这个赌博恰好公平，而在没有股息的状态下，另一类预期一期的总回报为 11/9，无风险回报为 4/3，最低一致价格是在由持有者的一步概率拼接出的测度（spliced measure）下的股息现值（本书的推导；数学框 20.1）。9

20.1.9 没来的消息的三种读法

本书把一段没有交易的时间读出三种意思（本书的判断）。在 Easley 与 O’Hara（1992）的模型里，市场不知道信息事件（information event）有没有发生，没有新信息时，没有交易的可能性更大（3.3 节）。在 Diamond 与 Verrecchia 的模型里，禁止卖空时没有交易是坏消息，只有所得款项限制时没有交易不改变报价（20.1.4 节）。在 Lee（1998）的模型里，交易成本（transaction cost）可能使许多依次交易的交易者无法把他们的私人信息显露出来，所以隐藏的信息在市场里积累，可能由一个小的触发因素释放出来，这时波动很高，同时没有任何相应的事件（21.2.5 节）。同样的沉默因此有不同的意思，要看它出自“有没有发生什么”的不确定、出自卖空禁令，还是出自固定的交易费用（trading costs），读的时候要先说明适用哪一种情形（本书的判断）。10

20.1.10 电视上的坏消息

5.5 节给出了 Busse 与 Green（2002）对 2000 年 CNBC 的 Morning Call 和 Midday Call 里股票报道的测量，结果是价格对负面报道的反应比对正面报道的反应更渐进，这在它的边界框所述的限度之内。就异常收益（abnormal return）的两种度量，Midday Call 的负面报道都导致累计异常收益，即把超出正常的收益加总起来，在随后一个月里越来越负、越来越显著，作者把它读作一个迹象，说明最初的反应可能是一个更大的长期反应的开始。在负面的 Morning Call 报道之后，作者称这个样本很小，只有五个交易日的 19 篇报道，异常表现在报道当天之后消失。

作者给出两种读法，卖空成本更高和对公司或行业其他负面公开消息（public news）的渐进反应（5.5 节），两者都没有检验；本节的知晓层和行动层也可以给出同样的形状，所以本书不采用任一种读法，也不印出这篇论文表格里的任何新数字（本书的判断）。11

20.1.11 传到持有者的披露

卖空受限、价格由依自己的看法交易的人定出，而他们不从交易或价格里读出别人的信息时，如 Miller 的论证，只有持有者能卖出，所以坏消息只有在改变了持有者的看法之后才使价格变动，披露必须传到他们那里（本书的判断）。有理性预期时，缺少知情的卖出本身就可以使报价变动，就像在 Diamond 与 Verrecchia 的模型里禁令之下没有交易那样（20.1.4 节和数学框 20.2）。Ljungqvist 与 Qian（2016）的卖空者在建仓之后发布做空报告（short-seller report）（工作论文版），发布把信息带给股东，股东的资本可以把价格压低（本书的判断；1.6.3 节、12.9 节和 19.3.1 节）。

20.2 信息逐步扩散与动量

Hong 与 Stein（1999）的模型是一座桥梁（bridge），把固定的传播过程连到价格上；本节把它与动量的另外三种来源并排放在一起，并回到分析师覆盖。

20.2.1 固定时间表上的新闻观察者

Hong 与 Stein 的新闻观察者（newswatcher）只根据他们私下观察到的消息作出预测，不读价格（工作论文版；16.1 节）。他们分成 zz 个同样大小的组，每个组都看到当前的股息水平，在每个时刻 tt，一个关于未来冲击的消息开始透露出来，分成 zz 个信息包，加起来就是它；在 tt 时刻每个信息包有一个组知道，在 t+1t + 1 时刻有两个组知道，依此类推，到 t+z−1t + z - 1 时刻，每个组都看到了全部信息（工作论文版）。所有新闻观察者都具有 CARA 效用，即常绝对风险厌恶（constant absolute risk aversion），在这种效用下，投入风险的数额不取决于财富，并有一个共同的风险厌恶参数；无风险利率为零，资产的供给固定为 QQ（工作论文版）。只有新闻观察者时，价格服从他们的方程 (1)，所以新信息在 zz 期里逐步进入价格，收益在短于 zz 的期限上正相关，价格从不越过它们的长期值（工作论文版；数学框 20.3）。如果新闻观察者读价格，在 QQ 是共同知识时，价格会完全揭示这些消息，所以他们不读价格这一假设，把反应不足（underreaction）建进了模型（工作论文版；16.5 节和 16.10 节）。

传播的一侧是预先固定的输入，一条确定性的线性时间表，每期增加一个组，人与人之间没有接触，也没有 S 曲线（S-curve）（本书的判断）。在关于抢跑者（frontrunner）的脚注里（20.2.2 节），作者指出，价格于是在没有动量交易时，应当不再有按消息线性调整这个不自然的特点（工作论文版）。Abreu 与 Brunnermeier 的套利者也按固定时间表得知消息（20.1.6 节），第 21 章把两者作比较。

与根模型相比，按本书的读法，Hong 与 Stein 改了几项默认（本书的判断；表 5.1）。没有人际接触的固定时间表取代了外部来源（external source）和口碑（word of mouth），使均匀混合（homogeneous mixing）没有可以适用的对象，路径是确定性的，如确定性平均场（deterministic mean field）之下那样。每一期都有消息到来，去掉了一次性注入（one-time injection）；各组各自只处理信息的一个子集（10.7 节），去掉了无限注意（unlimited attention），所以表 5.1 在无限注意那一行把本章写在括号里；按规则读过去价格的动量交易者（momentum trader）（20.2.2 节）去掉了不从价格学习，而且是与无限注意一同去掉的；对新闻观察者，不从价格学习这一条仍然保留。在表 5.1 为本章列出的放宽之外，CARA 效用取代了对数效用（log utility），为持有正的供给而设的一个固定折扣，即方程 (1) 里含 QQ 的项，取代了与总体风险无关的事实（fact unrelated to aggregate risk），动量交易者的订单流（order flow）是唯一变动的供给，取代了外生交易对手（exogenous counterparty）。

新闻观察者的交易好像要把头寸持有到最后，这是一种时间上不一致的简化，作者采用它，是因为它大大简化了分析，而且他们写道，他们没有理由相信它会左右他们的任何重要的定性结论（工作论文版）。12

20.2.2 动量交易者与过度反应

动量交易者同样具有 CARA 效用，但期限有限：在每个时刻 tt，新一代进入，持有头寸 jj 期（工作论文版），持有期（holding period）是 Hong 与 Stein 从模型外面设定的（本书的判断）。他们只以过去 kk 期的累计价格变动为条件，论文的大部分设 k=1k = 1，即最近一次价格变动；他们的订单流是一个常数加上 ϕ\phi 乘以最近一次价格变动，即方程 (3)，新闻观察者把它简单地当作一个不含信息的供给冲击（supply shock）（工作论文版；数学框 20.3）。如果动量交易者可以用价格变动的 nn 个滞后项来预测，每一项有自己的权重，作者怀疑在 nn 足够大时，他们的许多结果会消失（工作论文版）。

在均衡里 ϕ\phi 是他们方程 (7) 的解，其中 γ\gamma 是动量交易者的总风险容忍度（risk tolerance），即他们合在一起承担风险的意愿（工作论文版；数学框 20.3）。这样的均衡对任意的参数值不一定存在，作者一般地也无法排除多重均衡（multiple equilibria），所以他们的数值搜索总是选取 ϕ\phi 最小的那个（工作论文版）。在任何协方差平稳（covariance stationary）的均衡里，即方差与协方差不随时间变化的均衡，ϕ>0\phi > 0，所以动量交易者理性地追逐趋势（工作论文版）。

有两个命题在任何协方差平稳的均衡里成立。按命题 1，在一个正的单位冲击之后，价格的累计脉冲响应（impulse response），即自消息开始传播以来价格的总变动，峰值严格大于 1；如果 j≥z−1j \ge z - 1，它在 t+jt + j 时达到峰值，然后下降，最终收敛到 1；按命题 2，如果收益在短期限上正相关，那么有风险中性的动量交易者时，它们在某个不超过 j+1j + 1 的期限上负相关（工作论文版）。一个在好消息之后不久买入的动量交易者，对跟在他后面的人造成负外部性，而动量交易者分不清价格上涨来自消息还是来自更早几轮的动量交易（工作论文版；16.7 节）。

在他们的基准情形里，zz 为 12 个月，消息冲击的标准差为每月 0.5，γ\gamma 等于 1/3；jj = 12 个月时，ϕ\phi 为 0.2605（工作论文版的数字）。脉冲响应于是在冲击后 12 个月达到峰值 1.342，所以在峰值处价格超出长期基本面（fundamentals）变动 34.2%，收益的第一个负自相关出现在滞后 10 个月处（工作论文版的数字）。图 20.1 重画了这一基准（本书的计算）；只有新闻观察者时，价格沿一条直线上升，到第 11 个月达到 1（本书的推导；数学框 20.3）。

一项扩展有它自己的范围。抢跑者，按作者的定义，用他们私下观察到的消息预测短期价格变动，只要他们有一定的风险厌恶，并且像新闻观察者一样不从价格里提取信息，基本结果就仍然成立；他们使消息更快进入价格，但只要他们风险厌恶，就永远不会完全消除反应不足（工作论文版）。作者还直言，他们设计这个模型，就是要在短期限上给出正相关，在较长期限上给出负相关（工作论文版）。13

20.2.3 动量来源的比较

在本书里，先动量后反转（reversal）有几种模型来源，没有一种是唯一的解释（本书的判断；表 20.2）。Andrei 与 Cujean 的噪声理性预期模型（19.2.1 节）有滞后的动量，当且仅当那里的精度弹性（precision elasticity）超过 1，这要求私人信息以递增的速率流入。他们写道，从价格学习对他们的模型产生动量起着工具性的作用，而在 Hong 与 Stein 的模型里，如果投资者从价格学习，就不会出现动量，所以从价格学习在这两个模型里作用相反（本书的判断）。在 Pedersen 的模型里（19.2.2 节），不断回响各种看法的网络自己就产生动量（本书的判断），他对价值加动量策略在模型里有正的预期收益的证明，覆盖的是对称朴素情形（symmetric naive case）。

在 Daniel、Hirshleifer 与 Subrahmanyam（1998）的模型里（13.4 节），固定的过度自信（overconfidence）使价格变动在短滞后和长滞后上无条件负自相关，而经由有偏的自我归因（self-attribution）而变化的信心，在足够渐进的过度反应（overreaction）或纠正之下，给出无条件的短滞后正自相关和长滞后负自相关；因此，那里的过度自信只有在随结果变动时才给出无条件动量（本书的判断），而在 Scheinkman 与 Xiong 的模型里，对不同信号的过度自信给出转售期权（20.1.3 节）。

20.2.4 作为外部来源的分析师覆盖

在 Hong 与 Stein 的表 3 里，信息扩散越渐进，股票对动量交易者越有吸引力，因此在很宽的参数值范围内，导致更明显的过冲和更强的反转；分析师覆盖或许可以作为扩散速度的一个粗略代理，如果接受这个代理，覆盖较少的股票，大概是较小的股票，应当表现出更大的长期过度反应型的可预测性（工作论文版）。

Hong、Lim 与 Stein 通过引言里的非正式理论来读规模上的倒 U 形：较小的公司信息扩散可能更慢，这会带来更多动量，但做市能力大概也更薄，这可能在供给冲击之后带来更明显的反转（工作论文版）。在事件时间里，对其规模而言分析师多的股票，动量在大约十个月后耗尽，分析师少的股票的动量持续到大约两年的位置（工作论文版；1.8 节）。在他们强调的信息逐步扩散（gradual information diffusion）理论之内，作者把这读作高覆盖公司对滞后六个月收益里的信息反应不足大约 9%，一年不到就赶上，低覆盖公司反应不足约 20%，这些数字用的是经 beta 调整的收益，按残差覆盖分组，在同一个样本里（工作论文版的数字）。

有两条限制（本书的判断）。这个检验测量的是延续，即反应不足的一侧，没有检验 Hong 与 Stein 预测的长期反转（工作论文版）。Andrei 与 Cujean 补充说，Hong、Lim 与 Stein 的研究涉及截面动量（cross-sectional momentum），即股票相互比较，而 Hong 与 Stein 的模型和他们自己的模型涉及时间序列动量（time-series momentum），即每项资产自己的过去，这两种形式密切相关，但并不相同；他们还用流动性（liquidity）冲击解释了小公司的反转，这是与上面的做市能力薄并列的一种读法。

1.6.5 节把分析师覆盖读作根模型外部来源 α\alpha 的代理，它的强度可以因股票以及消息是好是坏而异（本书的判断）；这里同一个代理服务于两节，一是通过 20.1.2 节管理者的选择，处在输家与赢家不对称的背后，二是通过 Hong 与 Stein 的缓慢扩散，处在覆盖与动量之间的联系的背后（本书的判断）。15

20.2.5 两年内的小公司漂移

Bernard 与 Thomas（1989）的盈余公告后漂移（post-earnings-announcement drift），即价格在数月里朝着盈余意外的方向变动，对纽约证交所与美国证交所的公司在 1974 年至 1986 年间测量（5.5 节和 12.1 节），提供了一个对照。在他们的表 1 里，小公司的漂移，即盈余意外最高的减去最低的，在第 1 至 180 个交易日是 9.90%，在第 1 至 480 天是 9.99%，而中等公司从 8.85% 降到 7.72%，大公司从 4.47% 降到 3.61%，降幅约为 13% 和 19%（本书的计算）。因此，小公司的累计漂移到第 480 天，约两年的交易，没有显示净反转（本书的计算），不过在第 241 至 300 天，三种规模的差异都显著为负（12.1 节），所以“没有净反转”描述的只是小公司到第 480 天的累计漂移（本书的判断）。

盈余是公开消息，每个人在同一天都看得到，而 Hong 与 Stein 的过度反应涉及逐步传播的私人消息（本书的判断）。Hong 与 Stein 指出，如果动量交易者可以以公开公告的日期为条件，只在公告之后立刻追逐趋势，对公开消息就不一定出现过度反应，脉冲响应可能处处递增；如果他们没有这么精明，对公开消息的脉冲响应也是驼峰形的（工作论文版）。他们写道，重要的一点是，他们模型的逻辑容许、甚至强烈提示，对公开消息的反应可能不同于对私人信息的反应，他们称这一点显然可以检验（工作论文版）。小公司到第 480 天的净漂移符合第一种情形，不过它们在第 241 至 300 天的负漂移不符合，中等和大公司的降幅符合第二种；这些数据无法在这两种情形与 Bernard 与 Thomas 的读法之间作出裁决，他们的读法是市场没有认识到当期盈余对未来盈余的含义（本书的判断；12.4 节）。16

20.4 交易者的自查清单

这些问题没有一个说该买什么、卖什么，答得好也不会使一笔交易变得安全（本书的判断）。

  1. 坏消息在哪一层变慢？ 检查：消息是不是还没有传到足够多的人，知情的人是不是压不下价格，还是他们压得下，并且在等待，因为持有空头比持有多头更贵，这种延迟要求他们先后得知、错价从未成为共同知识、持有成本相对于错价足够大；在 Hong、Lim 与 Stein 的数据里（工作论文版），低覆盖与过去的输家分不开知晓层和行动层（本书的判断；20.1.1 节、20.1.2 节和 21.2.4 节）。
  2. 价格背后的分歧能学到吗？ 检查：卖空受限且分歧学不到时，若少数人就能吸收供给，Miller 的价格高于平均估值；在有理性预期、交易者与做市商风险中性、约束是共同知识、分歧来自信息时，Diamond 与 Verrecchia 的价格在给定公共信息时无偏，禁令使坏消息变慢，只限制未知情交易的约束使它变快，作者判断这一效应不太可能占主导（本书的判断；20.1.3 节和 20.1.4 节）。
  3. 谁能卖出？ 检查：卖空受限、没有人从交易或价格里读出别人的信息时，如 Miller 的论证，只有持有者能把价格压低，所以坏消息必须传到他们那里；有理性预期时，缺少知情的卖出可以使报价变动（本书的判断；20.1.4 节和 20.1.11 节）。
  4. 在周期的早期还是晚期，私人消息之后还是公开消息之后？ 检查：在 Hong 与 Stein 的模型里，只用一次过去价格变动的动量交易者分不清上涨来自消息还是来自更早的动量交易，而如果他们可以以公开公告的日期为条件、只在公告之后立刻追逐趋势，对公开消息就不一定出现过度反应（工作论文版；20.2.2 节和 20.2.5 节）。

20.5 小结

  • 坏消息可以在三个层面上变慢，即知晓、价格和行动，从价格到管理者的反馈又加上一种不对称的套利限制；检验必须说明它针对哪一层（本书的判断；20.1.1 节）。
  • 在 Hong、Lim 与 Stein 1980 年至 1996 年的美国数据里，在高于纽约证交所/美国证交所规模第 20 百分位的股票中，残差分析师覆盖低的地方动量更强，由过去的输家推动（工作论文版的数字）；管理者对坏消息的缄默是作者的解释，他们没有直接检验，而且这个交互效应分不开知晓层和行动层（本书的判断；20.1.2 节和 20.2.4 节）。
  • 在卖空受限、分歧又学不到时，Miller 的静态论证（当少数人能吸收供给时）以及 Harrison 与 Kreps 和 Scheinkman 与 Xiong 的转售期权（当意见不同且最乐观的群体可以变换时）使价格高于平均估值，而在后两者里，去掉带共同先验的贝叶斯更新就足够了，但并非必要（本书的判断）；在 Jarrow 的模型里，同样没有理性预期，偏差可以为正、为负或为零（据 Diamond 与 Verrecchia 的转述；20.1.3 节）。
  • 在有理性预期、交易者与做市商风险中性、卖空约束是共同知识、分歧来自信息时，Diamond 与 Verrecchia 的价格在给定公共信息时无偏；按比例约束知情与未知情交易者的禁令使调整变慢，对坏消息尤其如此，而只限制未知情交易的约束使它变快，作者判断这一效应不太可能占主导（20.1.4 节）。
  • 在 Jouini 与 Kallal 的模型里，设有简单策略、所有人共有一种信息结构，并且按本书的读法是价格接受者（price taker）（本书的判断），不能卖空的证券只需是上鞅，在增长率介于借出利率与借入利率之间的计价单位里、并在某个等价测度之下，所以它可以预期下跌而不提供套利；在均衡里，供给为正的资产在其持有者的边际替代率所诱导的测度下还必须是鞅（20.1.8 节）。
  • 在 Hong 与 Stein 的模型里，消息在不读价格的新闻观察者之间，按模型外固定的确定性线性时间表传播（本书的判断）；只有新闻观察者时，价格反应不足、从不过冲，而只用一次过去价格变动的动量交易者在任何协方差平稳的均衡里使价格过冲然后反转，在他们的基准里峰值为 1.342，作者怀疑，如果动量交易者用足够多的滞后项，这些结果中的许多会消失（工作论文版的数字；20.2.2 节和图 20.1）。
  • 动量在本书里有几种模型来源，Hong 与 Stein 的缓慢扩散与单变量规则（工作论文版），Andrei 与 Cujean 的私人信息加速流入与从价格学习，Pedersen 的网络，以及 Daniel、Hirshleifer 与 Subrahmanyam 的自我归因，而先延续后反转本身分不开它们（本书的判断；20.2.3 节）。
